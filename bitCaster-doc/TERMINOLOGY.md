# English and Japanese terminology

Use this table for public documentation and app copy. Keep wire values and code
identifiers unchanged. Choose the term for the action being described.

This table is the mapping between the English and Japanese text. Add a row
before you use a new product term in either language. Add a column when the
site gets another language.

| Concept | English | Japanese |
| --- | --- | --- |
| Determine a market's result | resolution | 結果判定 |
| Rules used to determine the result | resolution criteria | 結果判定基準 |
| Market state after trading closes, before the verified result | Awaiting resolution | 結果判定待ち |
| Market state after the verified result | Resolved | 結果判定済み |
| Complete a trade's exchange of assets | settlement | 決済 |
| Pay an amount | payment | 支払い |
| Receive a payout | claim payout | 報酬受取 |
| Winning portfolio position | Won | 当たり😋 |
| Losing portfolio position | Lost | ハズレ😭 |
| Unit for a count of shares | shares | 枚 |
| Prepaid anti-spam fee for order admission | Participation Score | Participation Score |
| Release stage of the product | beta | ベータ版 |
| The product category | prediction market | 予測市場 |
| One question that people trade on | market | マーケット |
| Token that pays out if its outcome wins | share | シェア |
| Token type behind a share | conditional token | 条件付きトークン |
| The shares that a wallet holds in a market | position | ポジション |
| Party that signs a market's result | oracle | オラクル |
| The unsolved risk that an oracle lies | oracle problem | オラクル問題 |
| Service that issues and redeems tokens | mint | ミント |
| Service that matches orders | matching engine | マッチングエンジン |
| List of open orders in a market | order book | 注文板 |
| An order is matched | fill | 約定 |
| Move bitcoin into the wallet | deposit | 入金 |
| Move bitcoin out of the wallet | withdraw | 出金 |
| Amount charged for an action | fee | 手数料 |
| Bot that quotes both sides of a market | market maker | マーケットメーカー |
| Non-refundable budget given to the market maker | funding | 資金提供 |
| Depth available to trade against | liquidity | 流動性 |

Do not replace settlement terms with resolution terms. Keep the result text
available to assistive technology. Do not use an emoji as the only result cue.
When changing a losing-position label, retain the warning that token deletion
is irreversible.

Keep the name Participation Score in English and Japanese text. Use Score as its
short form after the first use. Do not use Engine Score.
