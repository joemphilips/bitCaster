# English and Japanese terminology

Use this table for public documentation and app copy. Keep wire values and code
identifiers unchanged. Choose the term for the action being described.

| Concept | English | Japanese |
| --- | --- | --- |
| Determine a market's result | resolution | 結果判定 |
| Rules used to determine the result | resolution criteria | 結果判定基準 |
| Complete a trade's exchange of assets | settlement | 決済 |
| Pay an amount | payment | 支払い |
| Receive a payout | claim payout | 報酬受取 |
| Winning portfolio position | Won | 当たり😋 |
| Losing portfolio position | Lost | ハズレ😭 |

Do not replace settlement terms with resolution terms. Keep the result text
available to assistive technology. Do not use an emoji as the only result cue.
When changing a losing-position label, retain the warning that token deletion
is irreversible.
