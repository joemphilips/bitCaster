## bitCasterとは？

bitCasterは[Bitcoin](https://bitcoin.org/)と[Cashu](https://cashu.space/)上に構築された予測市場プラットフォームです。現実世界のイベント（選挙、スポーツ、天気など）の結果を表すトークンを売買します。予測が正しければ、トークンは額面の全額の価値があります。そうでなければ、無価値になります。

すべて完全にオープン仕様でオープンソースです。サーバーサイドにユーザー情報は保存されません。トークンはあなたのものです。ブラウザにローカル保存され、LightningまたはCashuを通じて即座に決済されます。

## できること

### あらゆるものを、あらゆる方法で取引

既存のマーケットを閲覧したり、任意の価格で指値注文を出したりできます。マーケットはバイナリ（Yes/No）、カテゴリカル（複数の結果）、さらには2次元にもなります。Lightning経由のBitcoinで取引します。ブリッジ不要、ガス代不要、ステーブルコイン不要です。

### 自分のマーケットを作成

誰でも新しいマーケットを提案できます。質問、可能な結果、解決基準を定義します。どのマーケットが許可されるかを決めるゲートキーパーはいません。

### オラクルになる

オラクルとは、現実世界の質問に答える人（または組織）です：*「チームXは勝ちましたか？」*、*「気温は30°Cを超えましたか？」*。誰でもオラクルを運営し、イベントの結果を証明できます。プロトコルにより、オラクルは説明責任を負い、その証明は暗号学的に検証可能です。

### トークン発行者になる

独自のCashuミントを運営して予測市場トークンを発行できます。ミントソフトウェアはオープンソースで、プロトコル仕様は公開されています。複数の独立したミントが共存でき、それぞれ異なるコミュニティやマーケットにサービスを提供できます。

## 仕組み

すべてのマーケット結果には対応するトークンがあります。トークンの価格は、その結果がどの程度起こりそうかについてのマーケットの集合的な推定を反映しています。70 satsで取引されているトークンは、マーケットがその結果の確率を約70%と見ていることを意味します。

イベントが解決されると、勝利トークンは全額（各100 sats）で償還可能になり、敗北トークンは無価値になります。決済は自動的で暗号学的です。中央の権威が支払いを行うことを信頼する必要はありません。

## デフォルトでセルフカストディ

トークンは**ベアラー証券**です。デジタルキャッシュのようなものです。サーバーではなく、ブラウザに存在します。アカウントの作成、パスワードの記憶、個人情報の提供は不要です。

ブラウザデータを消去すると、トークンは失われます。物理的な財布を紛失するのと同じです。トークンデータを安全に保つためにバックアップしてください。

## なぜBitcoinとecashなのか？

| | bitCaster | 従来のプラットフォーム |
|---|---|---|
| **決済** | Lightning経由で即時 | 数分〜数日 |
| **手数料** | ほぼゼロ | ガス代 / 出金手数料 |
| **プライバシー** | 強力 — ecashは公開の痕跡を残さない | すべての取引がオンチェーンまたはデータベースで可視 |
| **ブリッジ** | 不要 — ネイティブBitcoin | 多くの場合、特定チェーン上のステーブルコインが必要 |
| **アカウント** | 不要 | KYC / 本人確認 |
