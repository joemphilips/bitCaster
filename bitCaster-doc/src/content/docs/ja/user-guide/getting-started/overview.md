## bitCaster とは？

bitCaster は、[Bitcoin](https://bitcoin.org/) と [Cashu](https://cashu.space/) の上に作られた予測市場です。選挙、スポーツ、天気など、現実の出来事の結果に対応するシェアを売買します。予想が当たればシェアは払い出され、外れれば何も支払われません。

シェアの実体は [ecash](/ja/user-guide/core-concepts/ecash/) のトークンで、サーバーではなく、あなたのブラウザー（または CLI）のウォレットにあります。

## bitCaster でできること

### 予測市場に参加する

Lightning 経由の bitcoin を原資にして、市場でポジションを持つことができます。ポジションとは ecash のトークンで、将来特定の事象が発生した場合にのみ、1 sat と交換できるようになります。このトークンを 0 ~ 1000 msats (= 1 sat) の間の値段で売買することが、bitCaster の基本機能です。

### 予測市場を作る

誰でも、あらゆる事象についてのマーケットを作成できます。

基本的には質問を書き、考えられる結果を並べ、結果をどう判定するかを説明するだけです。詳しくは[マーケットの作成](/ja/user-guide/core-concepts/creating-markets/)を参照してください。

### オラクルになる

オラクルは、現実に何が起きたかを発表する審判です。**マーケットを作成した人がそのマーケットのオラクルになります**。

オラクルが嘘をつく危険性は古くから**オラクル問題**として知られており、完全な解決策は存在しません。bitCaster においては、オラクルはマーケット作成者であり、後から変更することはできません。オラクルの情報はそのユーザーのウェブ上のアイデンティティと結びついているため、評判 (reputation) ベースのシンプルな仕組みと言えます。

したがって、個々のユーザーが売買の前にオラクルが信用に値するかをチェックすることが推奨されます。

オラクルの判定を覆す「上訴」の仕組みにつきましては、現在導入を検討中です。

詳しくは[マーケットの結果判定](/ja/user-guide/core-concepts/resolution/)を参照してください。

## ウォレットを守るのはあなた自身

トークンの実体は、ブラウザーに保存された署名付きのデータにすぎません。これにより、ユーザーはトークンを bitCaster の外でも自由に送信・交換でき、情報流出のリスクを最小限に抑えることができます。その代わり、パスワードを再発行してくれる人もいません。

ウォレットを作成すると、12 語の復元フレーズが発行されます。紙に書き写し、オフラインで保管してください。フレーズがあれば、どのブラウザーでも資金とポジションを復元できます。フレーズがなければ、ブラウザーを失った時点で資金も失われます。詳しくは[ウォレットをバックアップする](/ja/user-guide/getting-started/wallet-backup/)を参照してください。

## それでも信頼が必要なもの

bitCaster は信頼しなければならない相手を大きく減らしますが、ゼロにはしません。

- ミントへの信頼: トークンの裏付けとなる bitcoin はミントが保管するため、出金に応じてくれることをミントに頼ることになります。
- オラクルへの信頼: 結果を決めるのはオラクルです。有効な署名が示すのは「誰が報告したか」であり、「それが正しいか」ではありません。上述のようにオラクルが嘘をつく可能性があります。

この二つに問題がない限り資産を失うことはありません。bitCaster そのものは単なるマッチングエンジンであり、交換相手を探すのに便利というだけの機能です。

## アイデンティティ

現在 bitCaster は [Nostr](https://en.wikipedia.org/wiki/Nostr) アカウントをユーザーアイデンティティとして使用しています。将来は別の ID でのログインもサポートを検討しています。

## はじめよう

[bitcaster.market](https://bitcaster.market/markets) を開き、ウォレットを作成し、復元フレーズを書き写してから、少額の取引を試してみてください。コマンドラインや AI エージェントを使いたい場合は、[AI エージェントに取引を任せる](/ja/user-guide/getting-started/ai-trading/)を参照してください。
