bitCaster は、オープンなプロトコルでつながった、いくつかの独立した部品でできています。ウォレットはあなた自身の端末の中にあり、それ以外はすべてのユーザーが共有します。

<ArchitectureFlow lang="ja" />

## アプリ

アプリはブラウザーで動き、ウォレットを保持します。トークンを動かす際はミントと、マーケットを読んだり注文を出したりする際はマッチングエンジンと通信します。

## ミント

ミントは ecash とマーケットのシェアを発行し、その裏付けとなる bitcoin を保管します。マーケットの結果判定時には、オラクルの署名を検証し、当たったシェアに払い出します。ベータ期間中のミントは、bitCaster が運営する 1 つだけです。ミントが稼働し続け、出金に応じることを、ユーザーは信頼することになります。

## マッチングエンジン

マッチングエンジンは、マーケットごとの注文板を管理し、買い手と売り手をマッチングし、価格をリアルタイムで配信します。ウォレットを預かることはありません。注文ごとに受け取るのは、その注文のためにロックされたトークンだけで、あなたが同意していない宛先へ送ることはできません。

## オラクル

マーケットのオラクルは、そのマーケットを作成した人です。作成時に出来事をアナウンスし、出来事が終わったら結果に署名します。署名された結果はミントに渡され、ミントは署名を検証してから払い出しに応じます。オラクルは bitCaster の一部ではありません。自分の鍵を持つ一人のユーザーであり、マーケットの結果を決められるのはその鍵だけです。

## オープンソースの範囲

アプリ、コマンドラインクライアント、ミント、プロトコル仕様は、すべて [bitCaster リポジトリ](https://github.com/joemphilips/bitCaster)で公開されています。資金に触れる部分はすべて自分で確認できます。マッチングエンジンだけはクローズドソースです。スパム対策の裏をかかれにくくするためです。ただし [API 仕様](https://github.com/joemphilips/bitCaster/tree/main/BitCaster.MatchingEngine.Contracts/specs)は公開されているので、誰でも対応するクライアントを作れます。
