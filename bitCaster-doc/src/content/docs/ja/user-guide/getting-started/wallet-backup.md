守るべき秘密は 2 つあります。ウォレットの復元フレーズと、Nostr 鍵です。どちらか一方から、もう一方を復元することはできません。

:::caution
限定ベータでは、暗号化バックアップのサービスはまだ動いていません。ウォレットのバックアップは復元フレーズだけです。
:::

## 復元フレーズ

12 語の復元フレーズは、設定の Cashu の欄で確認できます。紙に書き写し、オフラインで保管してください。フレーズを知っている人は誰でもあなたの資金を使えます。サポートを名乗る相手にも、決して教えないでください。

## 新しいブラウザーへ移る

新しいブラウザーで「ウォレットを復元」を選び、フレーズを入力します。アプリが自動で、資金とマーケットのポジションをミントから復元します。マーケットが多いと数分かかることがあります。

安全に移るためのコツが 2 つあります。1 つ目は、進行中の取引が終わってから移ることです。処理中の注文を完了または返金できるのは、元のブラウザーだけだからです。2 つ目は、同時に使うブラウザーを 1 つにすることです。

復元を行うと、どのトークンが同じフレーズに属するかがミントに伝わります。その場合でも、あなたの Nostr ID はミントに伝わりません。

## 取引の途中でサイトデータを消さない

取引、支払い、返金が終わっていない間、ブラウザーにはフレーズからは作り直せない記録が保存されています。何かが止まって見えても、ブラウザーのデータはそのままにして、ウォレットが処理を終えるのを待ってください。データを消すと、その取引に関わる資金を失うおそれがあります。

## Nostr 鍵

Nostr 鍵は、bitCaster でのあなたの ID です。マッチングエンジンに対してあなたを識別し、コメントや、あなたが作成したマーケットの結果に署名します。ウォレットとは別のもので、復元フレーズからは復元できません。

アプリが鍵を生成した場合は、設定から Nostr を開き、**nsecを表示** を選んで、控えを人目に触れない場所に保管してください。ブラウザー拡張機能を使っている場合は、その拡張機能の側でバックアップしてください。マーケットの作成者は特に注意が必要です。鍵を失うと、自分のマーケットの結果を報告できなくなります。
