Web アプリは、使用中のウォレットデータベースをブラウザ内に保存します。さらに、
ブラウザによるストレージ整理、クォータ超過による削除、または以前使っていた
ウォレットへの切り替えによって残高が画面から消えないよう、復元可能な
ウォレットデータの暗号化コピーをアップロードします。Web アプリでは暗号化
バックアップがデフォルトで有効です。

Vault を復号できるのは、ウォレットの 12 語の復元フレーズから導出した鍵だけです。
バックアップサービスが保存するのはパディング済みの暗号文であり、proof、残高、
mint、マーケット、ポジションを読むことはできません。バックアップを復元しても、
サービスに資金を使用する権限は与えられません。

## サービスから見える情報

暗号化ですべてのメタデータが隠れるわけではありません。マッチングエンジンの
運営者は、認証済みアカウントと暗号化 Vault の関連、保存サイズとオブジェクト数の
概数、更新時刻、ネットワークメタデータを観測できます。内容と正確な残高は暗号化
されたままですが、ウォレットが活動中であることや、おおよその保有量が推測される
可能性があります。

この匿名性に関するメタデータをマッチングエンジン運営者に預けたくない場合は、
暗号化バックアップを無効にした完全ローカルモードのコマンドラインウォレットを
使用してください。このモードでは、完全な運用中ウォレット状態をローカルの
SQLite データベースに保存します。バックアップサービスが利用できない、または
データを失った場合に備え、コマンドラインの復元ツールには緊急用の
NUT-13/NUT-09 シード復元経路もあります。

## 複数のウォレット

1 つの認証済みアカウントで、複数の独立した暗号化 Vault を保持できます。Vault は
1 つのウォレットシードに属し、Vault 間で資金が移動することはありません。Web
アプリが表示するのは、現在開いている復元フレーズに対応するウォレットだけです。

- 新しい復元フレーズを入力すると、新しい空のウォレットが始まります。
- 以前使った復元フレーズを再入力すると、そのウォレットの最新の暗号化
  バックアップがダウンロードされ、再び開きます。

サービスが保持するのは Vault ごとに 1 つの現在のスナップショットであり、過去の
ウォレット状態の履歴ではありません。古いスナップショットには使用済みの proof が
含まれる可能性があるため、復元可能な旧バージョンとしては提供されません。

## 復元フレーズは必ず保管してください

暗号化バックアップは利便性と継続性のための機能であり、復元フレーズの代わりでは
ありません。12 語をオフラインで安全に保管してください。サービスが利用不能に
なったり、保存上限のためアップロードを拒否したり、データを失ったりする可能性が
あります。アップロードに失敗した proof はローカルストレージに残り、Web アプリが
バックアップ済みとして削除することはありません。

バックアップ対象は通常の復元可能なウォレットデータです。進行中の P2PK/HTLC
スワップで使う一時的な秘密情報と条件付き proof は、スワップ中はローカルにだけ
保存されます。そのため、スワップの途中でブラウザウォレットを閉じると、通常残高を
後で復元できても、取引をそのまま継続できない場合があります。
