# 数値マーケット

数値マーケットの作成と取引は、現在のプロダクトでは利用できません。以下はプロトコルを読むための将来の数値アウトカムモデルです。プロダクトが対応する数値取引表現を公開するまでは、`numeric` のマーケット作成リクエストを送信したり、数値の取引価格を期待したりしないでください。

将来の数値モデルは、指定した日のビットコイン価格など、測定した値を結果として使います。カテゴリ型マーケットは、これとは異なり、名前を付けたアウトカムを使います。

## 仕組み

数値マーケットは範囲 `[lo_bound, hi_bound]` を定義します。オラクルがその範囲内の値 `V` を証明した場合：

- **HIトークン保有者**は、`V` が `hi_bound` にどれくらい近いかに基づいて比例配当を受け取ります
- **LOトークン保有者**は、補完的な配当を受け取ります

例：範囲 `[0, 100000]`、証明値 `V = 20000` の場合：

- HI保有者はシェア額面の20%を受け取ります
- LO保有者は80%を受け取ります

## BTC専用

bitCasterの数値マーケットは**ビットコイン（sats）**を基準資産として使用します。これは意図的な設計選択です：

- 数値マーケットは非常に細かい価格精度（0.0001%まで）が必要です
- フィアット通貨でこの精度を実現するには、サブセントのecash単位が必要になり、複雑さと互換性の問題が生じます
- BTCの `msat`（ミリサトシ）単位はCashuプロトコルでネイティブにサポートされており、十分な粒度を提供します

### 将来のシェア額面

予定するシェア額面は1,000 satsです。これは、HIまたはLOの各シェアに対する固定配当ではありません。結果によって各配当の割合が決まります。上の例では、ミント手数料を引く前の配当は、HIの1シェアで200 sats、LOの1シェアで800 satsです。この配当額は購入価格ではありません。

予定する価格単位はシェア額面の0.0001%です。これは、その単位のすべての価格で取引できるという意味ではありません。現在のリリースは数値取引に対応していません。

## 将来の数値マーケットの作成

将来のリリースで数値マーケットが利用可能になった場合：

1. 結果の範囲を選択します（例：BTC価格 $0〜$100,000）
2. 開始確率や作成前の資金提供なしでマーケットを登録します
3. 作成後の独立したフローでマーケットメーカーに資金を提供します
4. トレーダーは価格予想に基づいてHIまたはLOトークンを購入できます

## なぜフィアット数値マーケットはないのですか？

フィアット建ての数値マーケットには、シェアあたりの非常に大きな配当またはサブセントの ecash 単位が必要です。このプロダクトはフィアット担保に対応しません。sat 専用の担保境界を明確に保ちます。
