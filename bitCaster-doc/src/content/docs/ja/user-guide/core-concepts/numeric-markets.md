# 数値マーケット

数値マーケットでは、特定の日付のビットコイン価格など、将来の値に対してベットできます。結果が単純なカテゴリであるYES/NOマーケットとは異なり、数値マーケットには可能な値の範囲があります。

## 仕組み

数値マーケットは範囲 `[lo_bound, hi_bound]` を定義します。オラクルがその範囲内の値 `V` を証明した場合：

- **HIトークン保有者**は、`V` が `hi_bound` にどれくらい近いかに基づいて比例配当を受け取ります
- **LOトークン保有者**は、補完的な配当を受け取ります

例：範囲 `[0, 100000]`、証明値 `V = 20000` の場合：
- HI保有者はシェア額面の20%を受け取ります
- LO保有者は80%を受け取ります

## BTC専用

bitCasterの数値マーケットは**ビットコイン（sats）**を基準資産として使用します。これは意図的な設計選択です：

- 数値マーケットは非常に細かい価格精度（0.0001%まで）が必要です
- フィアット通貨でこの精度を実現するには、サブセントのecash単位が必要になり、複雑さと互換性の問題が生じます
- BTCの `msat`（ミリサトシ）単位はCashuプロトコルでネイティブにサポートされており、十分な粒度を提供します

### ユーザーへの影響

- **1シェアあたりの配当**: 1,000 sats（BTC価格$60k時で約$0.60）
- **価格精度**: 1ティックあたり0.0001%
- **最小取引単位**: ほとんどのユーザーにとって手頃な価格

## 数値マーケットの作成

数値マーケットを作成する場合：

1. 結果の範囲を選択します（例：BTC価格 $0〜$100,000）
2. satsでマーケットメーカーに資金を提供します
3. トレーダーは価格予想に基づいてHIまたはLOトークンを購入できます

## なぜフィアット数値マーケットはないのですか？

フィアット建ての数値マーケットは、シェアあたりの非常に大きな配当（小規模トレーダーには高額すぎる）またはサブセントのecash単位（複雑でエラーが発生しやすい）のいずれかが必要になります。需要が十分にあれば将来的にフィアットサポートを追加する可能性がありますが、現時点ではBTC専用がシンプルでアクセスしやすい設計です。
