bitCaster であなたが持つものは、残高もポジションも、すべて **ecash のトークン**です。このページでは、それが何を意味するのか、そしてなぜブロックチェーンよりも予測市場に向いているのかを説明します。

## ecash とは？

ecash は、ブラインド署名にもとづくデジタルな現金です。ブラインド署名は、David Chaum が 1980 年代に発表したアイデアです。

銀行が紙幣を発行するように、**ミント**がトークンを発行し、本物である証として 1 つ 1 つに署名します。この署名は「ブラインド」で、ミントは中身を見ずに署名します。後からトークンが本物かどうかは確認できますが、誰が受け取ったものかは分かりません。そして紙幣と同じく、トークンは持っている人のものです。アカウントも、ログインも、ID も紐づいていません。

bitCaster では、Lightning で bitcoin を入金すると ecash を受け取ります。シェアを買うと、その ecash は特定の結果に結びついた[条件付きトークン](/ja/user-guide/core-concepts/conditional-tokens/)に交換されます。当たれば通常の ecash に戻り、いつでも Lightning で出金できます。

## なぜ Cashu なのか？

bitCaster は、Bitcoin 向けの ecash プロトコルである [Cashu](https://cashu.space/) を使っています。仕様は [NUTs](https://github.com/cashubtc/nuts) と呼ばれる文書群として公開されていて、誰でもウォレットやミントを実装できます。暗号の仕組みは監査や拡張がしやすいほどシンプルで、bitCaster はその上に条件付きトークンを追加しています。Lightning とは最初からつながっていて、ブリッジやラップドトークンは要りません。さらに、複数の独立したチームがウォレット、ミント、ライブラリを開発しています。

## なぜブロックチェーンではないのか？

Polymarket が Polygon の上で動いているように、なぜ bitCaster もブロックチェーンの上で動かさないのか、とよく聞かれます。

答えは、取引所はもともと中央集権的だからです。誰かが注文板を運営し、注文をマッチングしなければなりません。その処理をオンチェーンに載せても運営者はいなくなりません。コストが増えるだけです。

まず、プライバシーが悪化します。パブリックチェーンでは、すべての取引が誰にでも、永久に見えてしまいます。ecash なら、誰がどのトークンを持っているのかはミントにさえ分かりません。次に、速度とコストが悪化します。オンチェーン決済にはガス代とブロック待ちが付きもので、どちらもマーケットが盛り上がったときほど跳ね上がります。そして、始めるまでの手間が増えます。最初の取引の前に、正しいチェーンの正しいコインと、ガス用のトークンまで用意しなければなりません。bitCaster なら、sats を入金すればすぐに取引できます。

ブロックチェーンが優れているのは、公開検証性と検閲耐性です。しかし予測市場では、すべての取引が公開されている必要はありません。それにマッチングエンジンは、どのみち注文を拒否できます。トレーダーが本当に求めているのは、プライバシー、速度、安い手数料であり、それを実現するのが ecash です。

## ecash にできないこと

ecash は魔法ではありません。トークンの裏付けとなる bitcoin はミントが保管するため、出金に応じてくれることをミントに頼ることになります。プライバシーが守られるのはミントに対してであり、マッチングエンジンには、あなたの Nostr 鍵で出した注文が見えます。また、トークンは持っている人のものなので、[復元フレーズ](/ja/user-guide/getting-started/wallet-backup/)を失えば資金も失われます。
