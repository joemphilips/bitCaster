# マーケットの作成

多くの予測市場プラットフォームでは、どのマーケットが存在するかを決めるのは運営者だけです。bitCasterは異なります。誰でも、いつでも、あらゆるテーマのマーケットを作成できます。必要なのは、イベントに答えを与えるオラクルと、初期流動性を提供するための資本だけです。

マーケットの作成とは、イベントの内容を定義し、結果を証明する人(オラクル)を決め、トレーダーがすぐに取引を開始できるよう資本を投入することです。

## オラクルの選択

bitCasterのすべてのマーケットは、少なくとも1つの**オラクルアナウンスメント**に紐づいています。これは、オラクルが特定の将来のイベントについてアテステーションを行うという署名付きの宣言です。アナウンスメントは標準的なDLCオラクルフォーマットに従います。Nostrイベント（Kind 88）として公開すると発見性と監査可能性が高まりますが、リレーが利用できない場合でも、署名済みアナウンスメントをミントとマッチングエンジンへ直接登録できます。

賭けたいイベントに既にオラクルアナウンスメントがある場合、例えばBitcoin価格のアテステーションを毎日公開している有名なDLCオラクルがあれば、それを選択するだけで済みます。

しかし実際には、興味深いマーケットのほとんどは、既存のオラクルがまだアナウンスしていない新しいイベントに関するものです。「X社はQ3までに機能Yをリリースするか？」「7月1日に東京で雨が降るか？」といった問いは、たいていまだ誰もアテステーションすることをコミットしていません。この場合、マーケット作成者は同時にオラクルにもなります。自分のオラクル鍵を設定し、自らアナウンスメントを作成して、イベントが解決した際に結果を証明することを約束します。

予測市場では必ずオラクルに対する信頼が発生します。誰を信頼するかの根本的な選択は各トレーダーに委ねられています。

## ベースアセット

すべてのマーケットには**ベースアセット**があり、担保・ステーク・建値支払いの単位を決定します。現在対応している値は次の2つです。

- **sat** — 金額をサトシ単位で表します。入金はLightning経由の通常ecashです。
- **usd** — 金額をUSセント単位で表します（BTC担保）。入金は見積もり時点のBTC/USDレートでLightning Bitcoinインボイスとして発行され、USDセントとしてクレジットされます。

JPYおよびその他の単位はまだ利用できません。

sat以外のマーケットでは、bitCasterは対象となる条件の担保が選択したベースアセットと一致することをミントに確認します。ミントがまだ単位を確認できない場合、マーケット登録は再試行可能なエラーを返します。ミントに条件が登録されてから再度お試しください。

## 価格分母

すべてのマーケットには**価格分母**（D）があります。現在のユーザー向けマーケットでは `D=10000` を使います。これにより `0.01%` の価格精度となり、アプリは **53.27%** のように小数第2位までの価格を表示できます。

- **価格の細かさ。** 価格は1からD−1の整数で表されるため、最小の価格変動は1/Dです。
- **1枚あたりの額面。** Dは価格精度を決めます。1枚あたりの額面はマーケット単位で固定されます。satマーケットの1枚は、勝った場合 **1000 sats** を受け取ります。USDマーケットの1枚は、勝った場合 **$1.00** を受け取ります。
- **決済精度。** satマーケットの担保は **msat** で、D=10000（10 satsのshare）です。USDマーケットの担保は標準の **usd** セントで、D=1000（$10のshare）です。

価格分母と1枚あたりの額面は、マーケット登録後に変更できません。

## マーケットに資金提供する

マーケット作成が成功すると、bitCasterは任意の**マーケットメイカーに資金提供**ステップを表示します。資金提供を行うと、そのマーケットの自動マーケットメーカーが初期のBidとAskを注文板に出すための予算を持てます。これにより、新しいマーケットが空の注文板から始まる問題を和らげられます。

この入金には、マーケット作成者のNostr公開鍵と`fundAmm`フラグが付与されます。そのため、サービスはこれを引き出し可能なユーザー残高ではなく、AMMの建値予算として扱います。資金提供入金に含まれる作成者の公開鍵は、リクエストに署名するNostrアイデンティティと一致している必要があります。

マーケットメイカーへの資金提供は、マーケットのベースアセットに従います。satマーケットではsats、USDマーケットではミントのBTC担保USD ecashに裏付けられたドル金額として表示します。内部的な担保会計では、satマーケットはmsat、USDマーケットは標準のcents (`usd`)を使います。JPYおよびその他の単位はまだ利用できません。

資金提供ステップには、No liquidity、Minimal、Standard、Deep、Customの予算があります。二項マーケットのプリセットは、USDマーケットでは **$15 / $150 / $300**、satマーケットでは **1500 / 15000 / 30000 sats** という丸い金額で表示されます。カテゴリカルマーケットでは、有料ティアに`log2(アウトカム数)`が掛けられます。

**No liquidity**を選ぶと、マーケットはBotによる建値なしで利用可能になり、人間のメイカーが流動性を提供する必要があります。非常に小さいカスタム予算では、流動性が薄いことを示す警告が表示される場合があります。

AMMによる資金提供は、取引を立ち上げるためのものです。人間のマーケットメイカーを永続的に置き換えるためのものではありません。マーケットが成熟するにつれて、人間やプロのマーケットメイカーが、初期AMMの建値をより狭く、より情報の入った流動性で置き換えていくのが理想です。

資金提供の確認前に表示される開示文:

> この入金は返金不可です。市場が収束した場合、予算は価格に情報をもたらしたトレーダーへの支払いに使われる見込みです。クローズ時の残額はオペレーター収益となります。

## マーケットのライフサイクル

マーケットは2つのイベントのいずれかが到来するまで開いています。1つ目は、オラクルが発表したデッドライン — オラクルがアウトカムを証明することをコミットした時刻です。2つ目はアテステーション自体で、イベントがデッドラインより早く解決した場合は、より早く到着することがあります。どちらか先に到来した方がマーケットを閉じます。

マーケットが閉じた後は、新規の注文や入金は受け付けられません。それ以降は取引は終了し、勝者が条件付きトークンをecashに交換する償還フェーズに入ります。償還ウィンドウはマーケットごとではなくミントごとに設定され、そのミントが発行するすべてのマーケットに同じ長さが適用されます。
