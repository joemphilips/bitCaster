# マーケットの作成

マーケットを作成するには、質問と考えられる結果を決めます。
現在のアプリでは、作成者自身がオラクルを務めます。
イベントの結果が決まったら、その結果を報告する役割です。

登録時に開始確率を選んだり、マーケットメイカーへの資金提供を行ったりする必要はありません。
ミントが別途登録手数料を請求する場合があります。
アプリは処理を進める前に、その手数料への同意を求めます。
作成後の別のステップで、マーケットメイカーに資金を提供できます。
この支払いは返金されません。作成や資金提供では表示価格は決まりません。
確定した取引によって表示価格が決まります。

## オラクルとしての役割

作成フローでは、自分のNostr秘密鍵を使って、イベントの結果を報告するという
署名付きの約束を作ります。これをオラクルアナウンスメントと呼びます。
マーケットを作成する前に、オラクルの鍵を設定してください。
現在のウィザードでは、他のオラクルや既存のアナウンスメントを選択できません。

結果が明確で、自分が報告できる質問を選んでください。
取引する人は、あなたの報告を信頼する必要があります。
有効な署名があっても、報告された結果が真実であるとは限りません。
報告者の責任と取引終了後の流れは、[マーケットの結果確定](/ja/user-guide/core-concepts/resolution/)
を参照してください。

## 金額と価格

アプリは金額をBitcoinの小さな単位であるsatsで表示します。
USD、JPYなど、他の通貨による資金提供には対応していません。

Yes/Noまたはカテゴリカルマーケットでは、勝ったシェア1枚につき、
償還手数料を引く前の金額で1 satを受け取れます。購入価格は別の金額です。
価格は53.3%のように、0.1パーセントポイント刻みで表します。
これらの設定は固定されており、マーケット作成時に選ぶ必要はありません。

数値マーケットの作成と取引は利用できません。

登録を完了するには、ミントがマーケットの通貨を確認する必要があります。
この確認がまだ済んでいないと表示された場合は、ミントにイベントが登録されてから
再度お試しください。

## マーケットに資金提供する

マーケット作成が成功すると、bitCasterは任意の**マーケットメイカーに資金提供**ステップを表示します。これは作成後の独立したフローです。資金提供を行うと、そのマーケットの自動マーケットメーカーが注文板にBidとAskを出すための容量を持てます。作成後に承認された入金を複数回送ることができます。

この支払いは、このマーケットの Bot への返金されない補助金です。
自分の取引用ウォレットへの入金ではありません。マーケットのシェア、手数料収入、
出金権は得られません。このマーケットに割り当てた資金を別のマーケットに使うことは
できません。

プリセットの予算を選ぶか、任意の金額を入力します。最初の入金が承認されると、
作成者が開始確率を指定することなく Bot が動き始めます。追加の入金は資金を増やし、
次の取引が起きる前でも Bot の提示価格を変えることがあります。過去の取引を書き換える
ものではありません。先の Bot 取引がまだ決済中の場合、新しい資金による提示価格の
変更は待機します。その間、Bot は新たな約定を停止します。

ウィザードは、選択した予算で見込まれる初期板厚もプレビューします。Botが片側あたりおよそ何段の価格レベルを出せるか、各レベルがおよそ何枚のshareになるかを表示します。このプレビューはmint手数料前の概算なので、実際の提示深度はこれより低くなる場合があります。

**No liquidity** を選ぶと、Bot に資金を提供せずに作成を完了します。
選択した結果で利用できる流動性がない場合、`BUY` と `SELL` タブはメッセージと
`LIQUIDITY` へのリンクを表示します。後からそこで Bot に資金を提供できます。
非常に小さいカスタム予算では、流動性が薄いことを示す警告が表示される場合があります。

資金提供は公開マーケット価格を設定しません。公開価格を設定できるのは確定済み取引だけです。最初の確定済み取引の前はマーケットに価格がないため、アプリは **No trades yet** または em dash を表示します。Bid/Askのミッドポイントは注文入力の参考値にすぎません。

資金提供の確認前に表示される開示文:

> この入金は返金不可です。マーケットの結果が確定した場合、予算は価格に情報をもたらしたトレーダーへの支払いに使われる見込みです。クローズ時の残額はオペレーター収益となります。

## マーケットのライフサイクル

マーケットは2つのイベントのいずれかが到来するまで開いています。1つ目は、オラクルが発表したデッドライン — オラクルがアウトカムを証明することをコミットした時刻です。2つ目はアテステーション自体で、イベントがデッドラインより早く解決した場合は、より早く到着することがあります。どちらか先に到来した方がマーケットを閉じます。

マーケットが閉じると、取引は終了します。新規の注文やボットへの資金提供は受け付けられません。
期限による閉鎖だけでは、勝ったトークンは決まらず、返金も保証されません。
ミントが結果を受け付けた後にのみ、勝ったトークンをecashに償還できます。
償還期間は、ミントの各マーケットに共通の方針です。結果がない場合と償還のルールは、
[マーケットの結果確定](/ja/user-guide/core-concepts/resolution/)を参照してください。
