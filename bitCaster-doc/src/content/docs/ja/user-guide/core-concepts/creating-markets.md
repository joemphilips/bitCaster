# マーケットの作成

多くの予測市場プラットフォームでは、どのマーケットが存在するかを決めるのは運営者だけです。bitCasterは異なります。誰でも、いつでも、あらゆるテーマのマーケットを作成できます。必要なのは、イベントに答えを与えるオラクルと、初期流動性を提供するための十分なsatsだけです。

マーケットの作成とは、イベントの内容を定義し、結果を証明する人(オラクル)を決め、トレーダーがすぐに取引を開始できるよう資本を投入することです。

## オラクルの選択

bitCasterのすべてのマーケットは、少なくとも1つの**オラクルアナウンスメント**に紐づいています。これは、オラクルが特定の将来のイベントについてアテステーションを行うという署名付きの宣言です。アナウンスメントは標準的なDLCオラクルフォーマットに従い、Nostrイベント（Kind 88）として公開されます。

賭けたいイベントに既にオラクルアナウンスメントがある場合、例えばBitcoin価格のアテステーションを毎日公開している有名なDLCオラクルがあれば、それを選択するだけで済みます。

しかし実際には、興味深いマーケットのほとんどは、既存のオラクルがまだアナウンスしていない新しいイベントに関するものです。「X社はQ3までに機能Yをリリースするか？」「7月1日に東京で雨が降るか？」といった問いは、たいていまだ誰もアテステーションすることをコミットしていません。この場合、マーケット作成者は同時にオラクルにもなります。自分のオラクル鍵を設定し、自らアナウンスメントを公開して、イベントが解決した際に結果を証明することを約束します。

予測市場では必ずオラクルに対する信頼が発生します。誰を信頼するかの根本的な選択は各トレーダーに委ねられています。

## 初期流動性

注文がないマーケットは、誰も取引できないマーケットです。このコールドスタート問題を解決するため、作成者は初期流動性としてsatsを預け入れます。このsatsはアウトカムトークン（例：YESとNO）に分割され、**Constant Product Market Maker（CPMM）** に渡されます。CPMMは注文板上の幅広い価格帯に指値注文を自動配置するアルゴリズムです。

その結果、マーケットが開始した瞬間から取引可能な注文が存在します。YESが過小評価されていると考えるトレーダーはすぐに購入でき、NOが過小評価されていると考えるトレーダーも同様です。CPMMは取引が約定するにつれて価格を調整し、マーケットの傾く方向に動かします。

CPMMはシンプルで実績のある仕組みです。GnosisやPolymarketの初期でも同じアプローチが使われていました。しかし、資本効率は必ずしも高くありません。流動性をすべての価格帯に均等に展開するため、現実的に取引されない価格帯にも資本が配置されます。マーケット立ち上げ時にはこれで十分ですが、成熟したマーケットではより狭いスプレッドと重要な価格帯でのより深い流動性が求められます。

ここで手動マーケットメイカーの出番です。マーケットが注目を集めるにつれ、プロフェッショナルや経験豊富なトレーダーがCPMMよりも良い価格で独自の指値注文を出すことができます。実際に取引が行われる価格帯に流動性を集中させ、トレーダーにとってより有利な条件を提供します。こうなれば、作成者はCPMM流動性の一部または全部を引き出すことができます。マーケットは自律的な参加者によって維持されるようになります。
