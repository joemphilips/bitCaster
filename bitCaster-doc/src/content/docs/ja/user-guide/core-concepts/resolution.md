# リゾリューション

イベントの結果が判明すると、オラクルは**アテステーション**（結果に対する暗号署名）を公開します。このアテステーションにより、ミントは勝利トークンと敗北トークンを区別でき、勝利トークンは額面の全額で償還可能になります。

## オラクルモデル

bitCasterはリゾリューションに既存の**DLC（Discreet Log Contract）インフラストラクチャ**を再利用しています。DLCオラクルはbitCasterについて何も知る必要はありません。他のDLCアプリケーションと同様に、イベントをアナウンスし、後でアテステーションを公開するだけです。

- **特別な統合は不要** — 標準的なDLCオラクルならどれでもbitCasterマーケットに対応できます。
- **既存のインセンティブ構造がそのまま適用** — 例えば、オラクルが矛盾するアテステーション（同じイベントに対して2つの異なる結果を証明）に署名すると、数学的にオラクルの秘密鍵が漏洩し、運営能力が破壊されます。
- **透明な責任** — ユーザーは各マーケットの結果にどのオラクルが責任を持つかを常に正確に知ることができます。オラクルの公開鍵とイベント記述子は、賭けを行う前に確認できます。

## なぜ紛争ベースのリゾリューションではないのか？

Polymarketのようなプラットフォームは、結果に異議を唱えてトークン保有者の投票で最終的に決定するUMAのオプティミスティックオラクルに依存しています。このアプローチには根本的な問題があります：

- **紛争と投票は「オラクル問題」を解決しません — 曖昧にするだけです。** 明確に特定された当事者が現実を証明する代わりに、責任が分散された多層的なガバナンスプロセスが得られます。
- **共謀リスク** — UMAトークン保有者が共謀すれば、結果を操作できます。腐敗のコストは十分な議決権を取得するコストに過ぎません。
- **本当のオラクルは1層深く隠されている。** PolymarketのマーケットはPoS（Proof of Stake）ブロックチェーンであるPolygon上に存在します。UMAトークン保有者がPOLステーカーが同意しない結果に投票した場合、ステーカーはチェーンをフォークできます。これによりPOLトークン保有者が究極の「オラクル」になりますが、ユーザーは彼らに対する直接的な救済手段を持たず、この依存関係の存在すら認識していない場合があります。
- **複雑なインセンティブモデル** — 参加者はマーケットがどのように解決されるかを理解するために、紛争保証金、投票ラウンド、エスカレーション期間、トークンエコノミクスについて推論する必要があります。

bitCasterのDLCアプローチは反対の立場を取ります：**結果に責任を持つ人を明確にする。** オラクルは既知の公開鍵を持つ名前付きエンティティです。オラクルが嘘をついた場合に何を失うかはケースバイケースで異なります（評判、秘密鍵の漏洩、契約上の責任）が、ユーザーは常に誰が証明し、どのような回答をしたかを知ることができます。

## リゾリューション後

オラクルがアテステーションを公開すると、ミントは結果を処理します：

- **勝利トークン**は額面の全額で償還可能になります。
- **敗北トークン**は無価値になり、スワップや償還ができなくなります。

これは他の予測市場がリゾリューション後の決済を処理する方法に似ていますが、bitCasterのポジションはドル建てではなく、Bitcoinに裏付けられたecashトークンです。

## トークンの償還

償還により、**条件付きトークン**（結果にロックされたCTFトークン）を自由に使える**通常のecashトークン**に変換します。

- これらのecashトークンは、ミントに応じて**ステーブルコイン建て**または**BTC建て**のいずれかになります。
- **BTC建てトークン**は、Lightningで出金することでさらに実際のビットコインに償還できます。
- 償還は即時です。待機期間、ガス代、ブリッジは不要です。
