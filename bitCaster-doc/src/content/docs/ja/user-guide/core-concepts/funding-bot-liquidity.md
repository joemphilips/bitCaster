# Botの流動性に資金を提供する

Botは、ユーザーが取引できるように買い注文と売り注文を出します。
資金提供は、その注文に使うお金をBotに渡す操作です。
マーケットを作成するだけではBotに資金は入りません。
作成後も、どのユーザーでも資金を追加できます。

## 支払う前に

Botへの資金提供は**返金不可**です。
補助金であり、シェア、手数料収入、利益、引き出す権利を得る投資ではありません。
マーケット終了時に残った資金を受け取る権利もありません。
自分の取引に使うお金は、Botではなく自分の取引用ウォレットに入れてください。

提供した資金は、選んだ条件に割り当てられます。
Botはその条件の各アウトカムで使えますが、別の条件には使えません。
例えば、Alpha、Beta、Gammaが同じイベントのアウトカムである場合、
これらは一つの予算を共有します。

確定する前に金額と手数料を確認してください。アプリはsatsで表示します。
支払いを準備する前に、アプリは適用される受取手数料を差し引いた後も、必要な最小額以上になるか確認します。
Mintの手数料により、Botが使える金額は支払額より少なくなる場合があります。
支払いが完了しても、すぐに流動性が増えるとは限りません。
次の注文が約定する保証もありません。対応するMintが利用可能である必要もあります。

## 資金を追加する

マーケット作成後に、sats で金額を入力します。
資金提供はスキップできます。
この画面を閉じても、作成したマーケットは取り消されません。

既存のマーケットでは、`LIQUIDITY` タブを開きます。
対応するMintの資金を使い、画面の案内に従って支払います。
アプリで完了を確認してください。後から何度でも追加できます。
マーケット作成者である必要はありません。

支払いが保留中の場合は、その支払いの状態をアプリで確認するか再開してください。
リロード後も同じ支払いを再開します。支払いが「受領済み」でも、マーケットへの資金提供が反映されたとは限りません。
アプリでクレジット済みを確認してから、同じマーケットに別の資金提供を行ってください。
時間がかかっているという理由だけで、別の支払いを作らないでください。
別の支払いは、返金できない追加の補助金になります。

回復処理が未完了または利用できない場合、それは残高不足を意味しません。
ウォレット内に利用可能な資金が準備済みなら、リモートの回復を待たずに資金提供を続けられます。

## 資金提供で変わること

BotはLMSRという価格計算方式を使います。
最初の資金提供では、各アウトカムを均等に扱う初期状態から始めます。
資金提供者が開始確率を指定することはありません。

後から資金を追加すると、Botの注文数量が増えることがあります。
取引がなくても買値と売値が変わることがあります。
先行するBotの取引が決済中の場合、新しい資金の反映はその完了を待ちます。
待っている間、新しいBotの取引は一時停止します。

資金提供では公開マーケット価格は変わりません。
公開価格は、最後に確定した取引の価格だけを使います。
最初の取引前は **No trades yet** またはダッシュを表示します。
現在の注文価格と、最後の取引価格は異なる場合があります。

**Bot Budget** は承認された資金提供の額です。
Botの残金や、今すぐ取引できる金額ではありません。
注文全体が約定できるかどうかは、現在の取引プレビューで確認してください。

## 予算を選ぶ

予算が大きいほど、現在の価格付近でより多くのシェアを取引できる場合があります。
ただし、返金できない資金も多くなります。
予算が小さいと取引できる量は少なくなり、取引によってBotの価格が動きやすくなります。
注文板の厚さの推定値は、実際に利用できる流動性の保証ではありません。

注文が大きすぎて約定できない場合は、数量を減らしてみてください。
追加の資金提供が役立つ可能性をプレビューが示す場合にだけ、資金提供を検討してください。
価格の上限・下限やマーケットの利用停止など、資金提供では解決できない理由もあります。
資金提供ではシェアを買ったことになりません。
資金提供後に、新しい取引プレビューを確認してください。
資金提供と取引は別の操作です。

利用できる注文がない場合、`BUY` と `SELL` タブから `LIQUIDITY` に案内します。
約定可能な注文が利用できるようになると、取引フォームを表示します。
