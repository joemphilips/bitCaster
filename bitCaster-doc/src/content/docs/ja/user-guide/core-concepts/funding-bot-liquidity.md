マーケットは、取引相手がいて初めて役に立ちます。bitCaster は、マーケットごとにマーケットメイク Bot を動かせます。Bot が買い注文と売り注文を出すので、トレーダーは最初から売買できます。そのためには元手が必要で、それを用意するのが資金提供です。

## 投資ではなく、補助金です

資金提供は**返金されません**。シェアも、手数料収入も、引き出す権利も得られません。Bot の予算は、価格を真実に近づけたトレーダーへの支払いに使われることが想定されていて、マーケットのクローズ時に残った分は運営者のものになります。

ですから、資金提供そのもので儲けるためではなく、そのマーケットが存在し、流動性があってほしいと思うときに行ってください。自分の取引に使うお金は、自分のウォレットに入金してください。

## 資金提供の方法

マーケットを作成した直後に、アプリが資金提供を案内します。このステップは省略できます。その後も、オープンしているマーケットなら、誰でも **流動性** タブから何度でも資金を提供できます。金額は sats で指定します。

## 資金提供で変わること

Bot は、すべての結果が同じ確率の状態から始まります。資金が多いほど、現在の価格の近くで出せるシェアが増え、1 回の取引で価格が動く幅は小さくなります。

資金提供がマーケットの価格を決めることはありません。表示される価格は、常に直近の取引の価格です。そのため、資金は入っているのにまだ取引がないマーケットには、価格が表示されません。
