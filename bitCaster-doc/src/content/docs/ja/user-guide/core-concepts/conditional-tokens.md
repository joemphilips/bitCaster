# 条件付きトークン

条件付きトークンは、予測市場のポジションを表します。特定のイベントとアウトカムに対応します。通常の ecash とは異なり、受け取れる金額はマーケットの結果によって決まります。

## 価格と払い戻し

価格は、シェアを買うために支払う金額です。払い戻しは、結果の検証後に的中したシェアから受け取れる金額です。この2つは異なります。

通常の sat 建てマーケットでは、的中した1シェアにつき、ミント手数料を引く前の金額で1 sat を受け取れます。1シェア0.2 sats で10シェアを買う場合、手数料を除く購入額は2 sats です。そのシェアが的中すれば、ミント手数料を引く前の払い戻し総額は10 sats です。別のアウトカムが的中した場合、その払い戻しはありません。購入額と手数料を失う可能性があります。

表示価格は、結果を保証するものではありません。新しい注文がその価格で成立する保証でもありません。送信前に注文プレビューと価格保護を確認してください。

## 売買と受け取り

まず、対応するミントから通常の ecash を取得します。ポジションを買うと、通常の ecash を条件付きトークンに交換します。売る場合は、対応する流動性があれば、ポジションを通常の ecash に交換できます。イベント結果が出る前にも売り注文を送信できます。ただし、売却が成立する保証はありません。

ミントがオラクルの署名済み結果を受け入れると、的中したトークンを同じミントの通常の ecash に償還できます。償還は Lightning への出金ではありません。手数料とミントの償還期間も適用されます。

取引が終了しただけでは、結果は確定しません。オラクルの結果がない場合も、返金は保証されません。条件については[マーケットの結果確定](/ja/user-guide/core-concepts/resolution/)を確認してください。取引や償還が確定するまで、ウォレット記録を保持してください。的中しなかったトークンが通常の ecash に変わることはありません。結果が確定しただけでウォレット記録を削除してよいわけではありません。

## 信頼が必要な相手

オラクルは結果に署名します。ミントは署名を検証し、払い戻し規則を適用します。有効な署名があっても、結果が真実であるとは限りません。ポジションを買う前に、マーケットの質問とオラクルを確認してください。

Bitcoin 準備金はミントが保有します。償還には、ミントが義務を履行し、稼働を続ける必要があります。自分でウォレットの鍵を持っていても、このリスクはなくなりません。資金管理とプライバシーの制限については、[ecash](/ja/user-guide/core-concepts/ecash/)を確認してください。

## プロトコルの詳細

bitCaster は、NUT-CTF プロトコルに従う Cashu proof でポジションを表します。Conditional Token Framework は、担保と結果に依存するポジションを分けて扱います。アプリを使うために、プロトコルの識別子を自分で管理する必要はありません。

数値マーケットには、別の払い戻しモデルが計画されています。現在の製品では利用できません。計画中のモデルは、[数値マーケット](/ja/user-guide/core-concepts/numeric-markets/)を参照してください。
