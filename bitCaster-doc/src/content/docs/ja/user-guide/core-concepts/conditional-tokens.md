# コンディショナルトークンフレームワーク

**条件付きトークン（Conditional Token）** とは、予測市場における*ポジション*を表現する暗号学的アセットです。他のデジタルトークンと同じように保有・送信・取引できますが、額面での償還は特定の結果が真になった場合にのみ可能です。反対の結果が確定すればトークンは無価値になります。これが分散型の予測市場を可能にする基本要素です。どのマーケットも、本質的にはオラクルのアテステーションに対して決済される、複数のアウトカム条件付きトークンの集合に過ぎません。

## 由来: Gnosis から Polymarket、そして Cashu へ

**コンディショナルトークンフレームワーク（CTF）** は元々 Ethereum 上で [Gnosis](https://gnosis.io/) によって設計されました。*担保* と*ポジション* をきれいに分離したのが特徴で、担保資産と結果に条件付けられた償還可能なトークンを切り離して扱うことで、任意のアウトカムの組み合わせを合成可能な ERC-1155 トークンとして表現できるようにしました。

その後 [Polymarket](https://polymarket.com/) が同じフレームワークを Polygon 上の予測市場に採用し、現在ではオンチェーン予測市場の事実上の標準となっています。

bitCaster は、まったく異なる基盤に同じアイデアを再エンコードしています。公開ブロックチェーン上の ERC-1155 トークンの代わりに、bitCaster のポジションは **NUT-CTF** と呼ばれる Cashu ミントプロトコルの拡張によって発行される **Cashu ecashトークン** として表現されます。メンタルモデルは同じで、特定のアウトカムが証明されたときにだけ償還可能なトークンですが、より高速かつ高い匿名性を達成しています。

## 4層の暗号学的アセット

bitCaster のアセットモデルは4つのレイヤーからなるスタックとして理解できます。各レイヤーは下のレイヤーをラップし、表現力を追加する代わりに基底アセットの異なる性質とトレードオフします。

- **Layer 1 — Bitcoin.** ベースマネー。トラストレスで検閲耐性がありますが、活発な取引には流動性が低く不向きです。オンチェーン承認は遅く、手数料も無視できず、スループットも限られています。決済には適していますが、高頻度の注文フローには向きません。
- **Layer 2 — Lightning Network.** Bitcoin 上のトラストレスなスケーリングレイヤーです。Lightning は L1 の手数料・承認遅延の問題を、新たな信頼できる第三者を導入することなく解決します。支払いは下層 Bitcoin のタイムロックによって担保されます。その代わり、参加者はオンラインであること、およびチャネル流動性を管理することが求められるため、長期的な保管や受動的な保有には向きません。
- **Layer 3 — Cashuネイティブトークン.** 対応する [Cashuミント](/ja/user-guide/core-concepts/ecash/)が保有する Bitcoin 準備金を裏付けとする sat ecash です。ミント運営者に対してはカストディアルですが、即時・プライベート・手数料ゼロで動きます。初回リリースでは、ユーザーはミントの BOLT11 Lightning 支払い方式を使って L2 と L3 の間で価値を移動させます。
- **Layer 4 — Cashu条件付きトークン.** 予測市場における*ポジション*であり、Ethereumエコシステムで言うところの「セキュリティトークン」に相当します。L4 トークンはそれぞれ特定のイベントの特定アウトカムにロックされており、DLC オラクルがそのアウトカムを証明したときにのみ使用可能になります。ユーザーはマーケット上で売買することで L3 と L4 の間で価値を移動させ、解決時には勝利した L4 トークンが額面で L3 の ecash に決済され、敗北したトークンは期限切れになります。

初回リリースはこのスタックに従います。ユーザーはマッチングエンジンに支払う前に、対応ミントから sat ecash を取得します。マッチングエンジンへの支払いには、常に ecash を使います。ユーザーは CLOB 注文とミント決済を通じて Layer 3 と Layer 4 の間で価値を移動させます。

## なぜ4層構造なのか

各レイヤーは、下のレイヤーが上の仕事に適していないから存在します。Bitcoin は決済には完璧ですが取引セッションには重すぎます。Lightning は高速でトラストレスですが、オンラインノードとチャネル管理を必要とするため、取引の合間に価値を*保有*しておく場所としては快適ではありません。Cashu ネイティブトークンは高速でプライベートな残高には完璧ですが、アウトカム条件付きクレームを表現できません。Cashu-CTF トークンはポジションのエンコードには完璧ですが、マーケットが解決した後は意味を失い、L3 に戻る必要があります。このスタックにより、ユーザーは取引したいときに価値を上に移動させ、保有したいときに下に移動させることができ、しかもベースで Bitcoin の信頼モデルを離れる必要がありません。
