# コアCTFプロトコル

Conditional Timed Fungible（CTF）トークンは、`condition_id`（ミントがDLCオラクルアナウンスメントから導出する32バイトの16進識別子）にバインドされたキーセットを持つCashu ecash proofです。このバインディングにより、トークンはオラクルが特定の結果を証明した場合にのみ償還可能な条件付き請求権を表すことができます。

完全な仕様については、[GitHub上のCTF仕様](https://github.com/joemphilips/bitCaster/blob/main/nuts/CTF.md)を参照してください。
