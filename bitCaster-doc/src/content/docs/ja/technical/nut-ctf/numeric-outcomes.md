# 数値アウトカム

数値アウトカムマーケットでは、定義された範囲内の数値に解決されるイベントの取引が可能です。数値マーケット用のCTFトークンは、アウトカム区間全体のポジションを表すために特殊なキーセット構造を使用します。

完全な仕様については、[GitHub上のCTF数値仕様](https://github.com/joemphilips/bitCaster/blob/main/nuts/CTF-numeric.md)を参照してください。
