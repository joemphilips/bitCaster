# 分割と統合

CTFトークンは、ユーザーがポジションをより小さな単位に分割したり、結合したりできる分割・統合操作をサポートしています。これらの操作は、取引、部分的な償還、ポートフォリオのリバランスに不可欠です。

完全な仕様については、[GitHub上のCTF分割・統合仕様](https://github.com/joemphilips/bitCaster/blob/main/nuts/CTF-split-merge.md)を参照してください。
