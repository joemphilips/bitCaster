このセクションでは、bitCasterの技術的なアーキテクチャとプロトコルの詳細を解説します。システムの仕組みを深く理解したい開発者や技術に詳しい方を対象としています。

## ポートフォリオ監視 API

認証済みの `GET /api/v1/portfolio` エンドポイントは、ポートフォリオの初回表示に使う表示専用データを返します。レスポンスには、アクティブなウォレットの概要、最初の資産ページ、および選択した期間の価値履歴が含まれます。このデータはカストディを証明せず、支出を承認しません。

次のページを取得するには、返された資産カーソルを `GET /api/v1/asset-monitoring/assets` に渡します。継続ページの取得にポートフォリオエンドポイントを使わないでください。非公開レスポンスは `Cache-Control: no-store` を使います。API は、不正なクエリに `400`、非アクティブなウォレットに `409`、履歴読み取りの制限が満杯の場合に `429`、アクティブなストレージプロバイダーに制限付き監視リーダーがない場合に `503` を返します。
