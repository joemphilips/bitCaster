# Nostr Kind 88イベント

DLCオラクルアナウンスメントはNostr上でkind 88イベントとして公開されます。これらのイベントには、オラクルの公開鍵、イベント記述子（アウトカム定義）、およびアテステーションに必要なnonceポイントが含まれています。Cashuミントはこれらのアナウンスメントを使用して`condition_id`値を導出し、CTFキーセットを作成します。
