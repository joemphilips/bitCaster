<CommandBlock label="Start trading">

```sh frame="code"
bitcaster-cli order book <market-id>
bitcaster-cli order fee-preview --market <market-id> \
  --outcome Yes --side Buy --price 420 --amount-msat 1000 > fees.json
bitcaster-cli order submit --market <market-id> \
  --outcome Yes --side Buy --price 420 --amount-msat 1000 \
  --fee-consent-file fees.json
```

</CommandBlock>
<CommandBlock label="Create a market">

```sh frame="code"
bitcaster-cli market creation-quote --outcomes Yes,No
bitcaster-cli market create --creation-id <id> \
  --title "<question>" --description "<how it resolves>" \
  --outcomes Yes,No --maturity-epoch <unix-time> \
  --relay <relay-url> --max-wallet-debit-msat <msat>
```

</CommandBlock>
